# Dynamic subagent routing

Use `route-subagents` for explicit agent/model/effort requests or material delegation benefit.

Implicit route: derive `W` and `D`; select directly from static `route_table`. Use fitness math only for cross-family fallback/audit. Difficulty depends on cognition/risk, not length or repetitive volume. No external refresh, raw `I/C`, or API-USD/ChatGPT-credit equivalence.

Defaults: Spark=microtask; Luna=`max` unless positively simple; Terra=`high`, `max` if complex; Sol=`medium`, up to `xhigh` normally. Sol Max requires explicit request or confirmed ultra-complex indivisible need. Ultra=max reasoning+delegation: Luna allowed for independent homogeneous lanes; Terra limited to 2-3 disjoint lanes with material speedup; Sol explicit-request-only.

Explicit exposed profile wins. Unavailable explicit profile => stop; no substitution. Bound scope; avoid overlapping ownership/redundant retries; primary verifies and synthesizes.

For every spawn set `task_name=<scope>_<model>_<effort>` using model codes `sp/l/t/s` and effort codes `l/m/h/xh/mx/u`; lowercase and underscores only. Example: `scansione_rete_l_xh`.
